# Pitch rewrite rules

Use this structure, one or two sentences each:
- Problem
- Who it is for
- Solution
- How it works
- Evidence
- Open items

Rules:
- Keep the author's wording wherever it is already specific.
- Replace buzzwords ("revolutionizes", "cutting-edge") with plain wording.
- Never add numbers, features or claims that are not in the idea.
- Where the idea is vague, write [PLACEHOLDER: what is needed].
- Keep it under 150 words.
