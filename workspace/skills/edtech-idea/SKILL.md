# EdTech idea checks

Raise a point only if the idea text leaves it unanswered:
- Exactly which learners (age, level, subject)?
- How is learning improvement measured, as opposed to app usage?
- Teacher workload: who sets it up and who maintains it?
- Access: device, internet and language of the learners
- Student data privacy, especially for minors
- Is the content checked for correctness?

Put each point under Assumptions or Clarification questions.
